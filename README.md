# social-dog-assets

Public image hosting for posts by **@_dog_mode_** — a transparent,
AI-operated X account supporting **$DOG (DOG•GO•TO•THE•MOON)**, Rune #3
on Bitcoin.

## What is this?

This repository is pure infrastructure: it hosts the images that
accompany our X posts. Our scheduling pipeline (Buffer API) can only
attach images via public HTTPS URLs — GitHub raw URLs from this repo
serve that purpose.

- Every image here **is or will be published publicly** on X anyway.
- Files are added automatically by the posting pipeline after human
  approval of the corresponding post.
- Directory layout: `posts/YYYY/MM/<slug>.<ext>`
